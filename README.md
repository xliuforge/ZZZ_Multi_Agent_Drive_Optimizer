## 主要功能

- 导入 ZZZ Scanner Next 的 `export.json`、通用驱动盘 JSON 或本软件完整备份。
- 手工录入驱动盘，并支持截图 OCR 后人工确认。
- 卡片和表格两种库存视图，支持筛选、编辑、复制、归属与占用管理；可通过二次确认一键清空库存。
- 搜索指定 4 件套和多个可选 2 件套，统一比较并返回前 20 套结果。
- 4/5/6 号位支持同时选择多个主属性候选；只有最终实际采用河豚电音 2 件套的组合，5 号位才强制使用穿透率。
- 同时保存多个角色目标，并提供“严格顺序锁盘”和“全队协调模式”；后者会从每名角色前 20 套候选中联合寻找无冲突分配。
- 高优先级角色先锁盘，低优先级角色不能使用已经分配的盘。
- “重新计算此角色”始终只计算当前角色；“重新协调全队”会强制按全队协调模式重新联合分配。
- 库存与角色目标分别保存，避免所有数据集中在同一个状态文件。
- 所有内置角色均补齐基础冲击力、异常精通、异常掌控及适用的回复属性（命破使用闪能、锋御使用锐能自动累积），未装备对应加成时仍显示角色基础值；旧目标重新计算时会自动刷新角色与音擎资料。

## 面板目标与优先级

可填写以下九项期望属性：

- 暴击率
- 暴击伤害
- 攻击力
- 生命值
- 防御力
- 异常精通
- 异常掌控
- 能量回复
- 冲击力

九项输入框默认均为空；空白表示不参与目标筛选。属性优先级范围为 1～6，可重复设置：

- `1`：最高优先级
- `6`：最低优先级，也是默认值

排序规则由程序自动决定，不再需要选择“配装策略”：

1. 填写了任意面板目标：按属性优先级逐级贴近目标。
2. 没有填写目标，但勾选了有效词条：最大化所选有效词条。
3. 没有填写目标，也没有勾选有效词条：使用当前职业的默认评分。
4. 面板目标比较相同时：继续比较有效词条，再比较职业默认评分。

无法同时满足全部要求时，优化器先缩小高优先级目标的差距。结果说明会明确区分：

- 低于目标：`约差 x.xx 词条`
- 高于目标：`约高出 x.xx 词条`
- 与目标相同：`正好达到`

不同属性先按各自尺度归一化，再参与同优先级比较：暴击率按 2.4%、暴击伤害按 4.8%、攻击/生命/防御按对应基础属性的一次百分比词条、异常精通按 9 点、异常掌控和冲击力按 1 点、能量回复按 0.01。当前使用线性差距：低于目标承担完整惩罚，高出目标只承担同等归一化差距的 10%，因此排序倾向“宁可略高，不要低于目标”，但高出越多惩罚仍线性增加。

异常掌控没有副词条，主要由角色基础/核心强化、音擎高级属性、6 号位主属性和套装效果决定。百分比掌控处于同一加成区相加，例如法厄同之歌 2 件套的 8% 不作为独立乘区。

## 自定义有效词条

除能量回复和冲击力外，其余面板目标下方都有“计为有效词条”复选框，默认全部不勾选。能量回复和冲击力不存在副词条，因此只能作为面板目标和优先级条件，不计入有效词条。面板目标与有效词条选择互相独立，不需要填写目标才能勾选。

映射规则：

| 复选项 | 计入的驱动盘副词条 |
|---|---|
| 暴击率 | 暴击率 |
| 暴击伤害 | 暴击伤害 |
| 攻击力 | 攻击力%、固定攻击力 |
| 生命值 | 生命值%、固定生命值 |
| 防御力 | 防御力%、固定防御力 |
| 异常精通 | 异常精通 |

有效词条公式保持为：

```text
有效词条数 = 副词条最终数值 ÷ 单次词条数值
```

单次词条数值：

| 属性 | 1 词条 |
|---|---:|
| 暴击率 | 2.4% |
| 暴击伤害 | 4.8% |
| 攻击力% | 3% |
| 生命值% | 3% |
| 防御力% | 4.8% |
| 固定攻击力 | 19 |
| 固定生命值 | 112 |
| 固定防御力 | 15 |
| 穿透值 | 9 |
| 异常精通 | 9 |

勾选项会随每个角色目标分别保存，同时影响有效词条显示、综合词条排序和驱动盘副词条的绿色高亮。

## 配装结果

单角色每套候选、多角色实际分配和接近目标的候选均直接显示“配装后面板”，按职业展示适用属性：

- 普通职业：生命、攻击、防御、冲击、双暴、异常掌控、异常精通、穿透率、能量自动回复。
- 命破：显示贯穿力和闪能自动累积，隐藏穿透率、穿透值及普通回能。
- 锋御：以锐暴伤害替代攻击，以锐能自动累积替代普通回能。
- 适用时补充穿透值及已有的静态伤害加成；零值属性保留，旧结果缺失字段显示“—”。

此处数值为装备后的最终面板，贯穿力也采用初始攻击、生命和静态加成。触发后的属性保留在实战参考及展开明细中。

冲击力按以下方式计算：

```text
面板冲击力 = 角色基础冲击力 × (1 + 冲击力加成总和)
```

没有冲击力加成时直接显示角色基础冲击力。旧版保存的角色目标缺少基础冲击力字段时，程序会根据角色名自动补齐。

所有内置角色均保存基础冲击力、异常精通、异常掌控及适用的回复属性。没有装备加成时显示角色基础值；真斗的闪能自动累积为 0，仍按真实零值显示。

本版校准了多项实机面板数据：千夏核心技攻击力、照核心技生命值、法厄同之歌异常掌控计算，以及爱芮的基础异常掌控。示例固定组合“爱芮核心技 F + 壳中之灵 + 6 号位掌控 + 法厄同之歌 2 件套”按同区加成计算为约 253 掌控。

## 清空驱动盘库存

“2. 驱动盘库存”右上角提供“清空库存”按钮。执行前会显示驱动盘和已保存配装数量并要求二次确认。确认后将清除：

- 全部驱动盘；
- 已保存的角色配装；
- 驱动盘占用记录；
- 当前单角色和多角色计算结果。

多角色的角色要求配置保留。该操作无法撤销，建议需要时先导出完整备份。
## Scanner

面板目标支持“至少达到”“收益上限”和“尽量接近”三种类型。暴击率、暴击伤害、攻击、生命、防御和异常精通可独立选择；异常掌控、能量回复和冲击力因不存在驱动盘副词条，固定按“至少达到”处理，并继续支持目标优先级。

Scanner 使用独立项目 [ZztIsolation/ZZZ-Scanner.Next](https://github.com/ZztIsolation/ZZZ-Scanner.Next)。

点击“打开驱动盘扫描器”后，程序会：

1. 查找 EXE 同目录下已经安装的 Scanner；
2. 找不到时查询官方 GitHub Latest Release；
3. 下载 Windows x64 self-contained 包；
4. 按官方 manifest 校验下载包及文件；
5. 安装到 EXE 同目录的 `scanner` 文件夹并启动。

通过配装器启动 Scanner 时，扫描结果保存在：

```text
程序目录\scanner-outputs\
```

每次扫描会创建独立子目录。扫描完成后，在配装器中导入相应目录里的 `export.json`。
如果 Scanner 明确提示权限不足、无法读取游戏窗口或无法开始扫描，请关闭程序后右键 `ZZZ_Multi_Agent_Drive_Optimizer_v2.3.21.1.exe`，选择“以管理员身份运行”，再通过页面打开 Scanner。正常情况下不需要管理员权限。

## 数据文件

默认运行数据位于 EXE 同目录：

```text
state.json                    # 驱动盘库存和本地套装归属
state-character-targets.json  # 多角色配装目标
storage-config.json           # 自定义库存路径记录
scanner-outputs\              # Scanner 扫描结果
scanner\                      # 自动下载的 Scanner
```

这些运行时内容已加入 `.gitignore`，不会提交到仓库。页面仍可将库存改到其他目录；`storage-config.json` 只记录自定义路径。

首次运行时，如果程序目录没有数据，程序会尝试从旧 `%APPDATA%\ZZZDriveBuilder` 复制已有库存和角色目标。旧数据不会自动删除。

需要 Go 1.22 或兼容的新版本：

```powershell
go test ./... -skip '^TestBundledScannerIntegrity$'
```

## 配装区域布局

角色配置后的顺序为：当前角色的配装策略、属性阈值与优先级 → 驱动盘占用策略 → 配装目标与结果。快捷目录与步骤编号同步。

单角色候选与多角色目标、实际分配方案集中在“配装目标与结果”中。单角色结果仅在启动单角色配装后显示，保留当次计算角色名；清空结果后隐藏。多角色目标及分配结果在同一区域继续按角色展示。
