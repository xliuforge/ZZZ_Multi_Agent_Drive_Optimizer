# ZZZ Multi-Agent Drive Optimizer

《绝区零》本地驱动盘库存管理与多角色配装工具，面向 Windows x64。

## 项目来源

本项目 Fork 并改进自：

- **Upstream / 原版仓库：** [TonyUB/ZZZ_Drive_Disc](https://github.com/TonyUB/ZZZ_Drive_Disc)

感谢原作者提供驱动盘库存、基础面板计算、配装搜索及 WebUI 的初始实现。本分支在其基础上增加了多角色无冲突分配、角色和属性优先级、多个 2 件套候选、自定义有效词条、便携数据存储，以及 ZZZ Scanner Next 的自动下载和启动支持。

## 主要功能

- 导入 ZZZ Scanner Next 的 `export.json`、通用驱动盘 JSON 或本软件完整备份。
- 手工录入驱动盘，并支持截图 OCR 后人工确认。
- 卡片和表格两种库存视图，支持筛选、编辑、复制、归属与占用管理；可通过二次确认一键清空库存。
- 搜索指定 4 件套和多个可选 2 件套，统一比较并返回前 20 套结果。
- 同时保存多个角色目标，按角色优先级依次分配驱动盘，并按 P1、P2 等优先级汇总显示各组角色。
- 高优先级角色先锁盘，低优先级角色不能使用已经分配的盘。
- 每个角色可单独重新计算；如果新方案与后续角色冲突，只清除受影响的后续结果。
- 库存与角色目标分别保存，避免所有数据集中在同一个状态文件。
- 所有内置角色均补齐基础冲击力、异常精通、异常掌控和能量自动回复，未装备对应加成时仍显示角色基础值。

## 面板目标与优先级

可填写以下六项期望属性：

- 暴击率
- 暴击伤害
- 攻击力
- 生命值
- 防御力
- 异常精通

六项输入框默认均为空；空白表示不参与目标筛选。属性优先级范围为 1～6，可重复设置：

- `1`：最高优先级
- `6`：最低优先级，也是默认值

无法同时满足全部要求时，优化器先缩小高优先级目标的差距。结果说明会明确区分：

- 低于目标：`约差 x.xx 词条`
- 高于目标：`约高出 x.xx 词条`
- 与目标相同：`正好达到`

## 自定义有效词条

每项面板目标下方都有“计为有效词条”复选框，默认全部不勾选。面板目标与有效词条选择互相独立，不需要填写目标才能勾选。

映射规则：

| 复选项 | 计入的驱动盘副词条 |
|---|---|
| 暴击率 | 暴击率 |
| 暴击伤害 | 暴击伤害 |
| 攻击力 | 攻击力%、固定攻击力 |
| 生命值 | 生命值%、固定生命值 |
| 防御力 | 防御力%、固定防御力 |
| 异常精通 | 异常精通 |

有效词条公式保持为：

```text
有效词条数 = 副词条最终数值 ÷ 单次词条数值
```

单次词条数值：

| 属性 | 1 词条 |
|---|---:|
| 暴击率 | 2.4% |
| 暴击伤害 | 4.8% |
| 攻击力% | 3% |
| 生命值% | 3% |
| 防御力% | 4.8% |
| 固定攻击力 | 19 |
| 固定生命值 | 112 |
| 固定防御力 | 15 |
| 穿透值 | 9 |
| 异常精通 | 9 |

勾选项会随每个角色目标分别保存，同时影响有效词条显示、综合词条排序和驱动盘副词条的绿色高亮。

## 配装结果

多角色卡片中的“面板属性”固定展示：

- 生命、攻击、防御、冲击力
- 暴击率、暴击伤害
- 贯穿力
- 异常掌控、异常精通
- 穿透率、能量回复

该区域只显示面板口径，不混入音擎技能或条件触发后的实战属性，也不使用绿色高亮。

冲击力按以下方式计算：

```text
面板冲击力 = 角色基础冲击力 × (1 + 冲击力加成总和)
```

没有冲击力加成时直接显示角色基础冲击力。旧版保存的角色目标缺少基础冲击力字段时，程序会根据角色名自动补齐。

所有内置角色均保存基础冲击力、异常精通、异常掌控和能量自动回复。没有对应驱动盘或套装加成时，结果显示角色自身基础值，而不是 `0`。

## 清空驱动盘库存

“2. 驱动盘库存”右上角提供“清空库存”按钮。执行前会显示驱动盘和已保存配装数量并要求二次确认。确认后将清除：

- 全部驱动盘；
- 已保存的角色配装；
- 驱动盘占用记录；
- 当前单角色和多角色计算结果。

多角色的角色要求配置保留。该操作无法撤销，建议需要时先导出完整备份。
## Scanner

Scanner 使用独立项目 [ZztIsolation/ZZZ-Scanner.Next](https://github.com/ZztIsolation/ZZZ-Scanner.Next)。

点击“打开驱动盘扫描器”后，程序会：

1. 查找 EXE 同目录下已经安装的 Scanner；
2. 找不到时查询官方 GitHub Latest Release；
3. 下载 Windows x64 self-contained 包；
4. 按官方 manifest 校验下载包及文件；
5. 安装到 EXE 同目录的 `scanner` 文件夹并启动。

通过配装器启动 Scanner 时，扫描结果保存在：

```text
程序目录\scanner-outputs\
```

每次扫描会创建独立子目录。扫描完成后，在配装器中导入相应目录里的 `export.json`。
如果 Scanner 明确提示权限不足、无法读取游戏窗口或无法开始扫描，请关闭程序后右键 `ZZZ_Multi_Agent_Drive_Optimizer_v2.0.0.exe`，选择“以管理员身份运行”，再通过页面打开 Scanner。正常情况下不需要管理员权限。

## 数据文件

默认运行数据位于 EXE 同目录：

```text
state.json                    # 驱动盘库存和本地套装归属
state-character-targets.json  # 多角色配装目标
storage-config.json           # 自定义库存路径记录
scanner-outputs\              # Scanner 扫描结果
scanner\                      # 自动下载的 Scanner
```

这些运行时内容已加入 `.gitignore`，不会提交到仓库。页面仍可将库存改到其他目录；`storage-config.json` 只记录自定义路径。

首次运行时，如果程序目录没有数据，程序会尝试从旧 `%APPDATA%\ZZZDriveBuilder` 复制已有库存和角色目标。旧数据不会自动删除。

## 启动与退出

正式版使用 Windows GUI 子系统构建，双击 EXE 不会弹出 Terminal。

- 点击页面右上角“退出程序”：立即结束本地服务。
- 直接关闭最后一个网页：约 5 秒后自动结束后台 EXE。
- 刷新页面或仍有其他页面打开：新页面会话/心跳会取消自动退出。

## 从源码构建

需要 Go 1.22 或兼容的新版本：

```powershell
go test ./... -skip '^TestBundledScannerIntegrity$'
go build -ldflags="-H=windowsgui" -o ZZZ_Multi_Agent_Drive_Optimizer_v2.0.0.exe .
```

`TestBundledScannerIntegrity` 用于检查另行制作的内置 Scanner 发行包；纯源码仓库没有预装 Scanner，因此普通源码测试应跳过该项。

## 仓库文件

- `main.go`：本地服务、存储、Scanner 安装和配装算法。
- `main_test.go`：后端、算法、界面标记和安全性回归测试。
- `web/`：嵌入 EXE 的离线 WebUI、角色图片和驱动盘资源；从源码构建时必须保留并提交。
- `web/data/characters.json`：角色基础属性、职业、属性与核心技成长数据。
- `web/data/wengines.json`：音擎面板属性及可计算效果。
- `web/data/release-order.json`：角色和音擎的版本排序。
- `tools/`：前端及数据校验脚本。
- `rsrc_windows_amd64.syso`：Windows AMD64 资源文件，构建时写入 EXE 图标和版本信息；源码仓库应保留。
- `app_icon.ico`、`app_icon.png`：应用图标源文件。
- `DRIVE_DISC_INTEROP.md`：通用驱动盘 JSON 互通说明。
- `ZZZ_Multi_Agent_Drive_Optimizer_v2.0.0.exe`：当前 Windows x64 发布版。
- `ZZZ_Multi_Agent_Drive_Optimizer_v2.0.0_使用说明.*`：Markdown、HTML 和 PDF 使用说明。

## 后续角色数据更新

角色与音擎资料已经从页面代码拆分为独立 JSON。新增角色时主要修改 `web/data/characters.json`、`web/data/wengines.json` 和 `web/data/release-order.json`，再补充头像与资源映射即可。构建前运行测试；角色缺少冲击力、异常精通、异常掌控或能量回复时，完整性测试会失败。
## 计算范围

本工具计算角色等级、所选核心技、音擎基础/高级属性、驱动盘主副属性及可静态计算的套装效果。

依赖动作、层数、敌人、队友或战斗条件的增益通常只作为实战参考，不写入角色详情面板。本工具不是完整的战斗伤害模拟器，请以游戏内实际表现为准。
