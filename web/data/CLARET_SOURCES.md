## 角色

S 级电属性锋御；全名克拉蕾·弗林特，罗斯凯利法·弗林特工坊。

| 项目 | 采用值 |
| --- | --- |
| 生命 / 防御 / 冲击 | 5651 / 441 / 93 |
| 异常掌控 / 异常精通 | 80 / 79 |
| 基础暴击率 / 基础暴伤 | 5% / 50% |
| 锐暴伤害 / 锐能自动累积 | 150% / 1.5 |
| 核心 0/A/B/C/D/E/F 常驻暴击加成 | 0/4.8/9.6/14.4/19.2/24/28.8% |
| 核心 0/A/B/C/D/E/F 触发暴击加成 | 15/17.5/20/22.5/25/27.5/30% |

正式服属性列表不再提供攻击力，JSON 的 `atk: 0` 为不适用值；不沿用测试服攻击力 626。`baseEnergyRegen: 0` 不代表锐能为零，锐能通过独立 `baseSharpnessRegen` 字段显示。

克拉蕾的每 1% 初始暴伤转换为 0.35% 初始暴击率，包含基础暴伤；转换只计算一次，不含实战暴伤。F 无装备初始暴击率为 `5 + 28.8 + 50 × 0.35 = 51.3%`。资料站列表的 33.8% 是未执行此转换的基础与核心合计。

令 `r` 为实战暴击率除以 100，`l` 为锐暴伤害除以 100，期望倍率为：

```text
(1 + clamp(r, 0, 1) × l) × (1 + clamp(r - 1, 0, 1) × l)
```

锐暴伤害 150% 时，100% 暴击对应 2.5 倍，150% 对应 4.375 倍，200% 对应 6.25 倍。面板可以显示超过 200% 的数值，但输出收益在实战 200% 封顶。指数使用最终防御而非攻击，防御沿用项目的向下取整规则。

## 套装与计算边界

荆棘玫瑰沿用项目已有数据：2 件套防御 +16%；4 件套伤害 +15%，初始防御达到 1000/1800 时暴击 +8/16%。本次实现四件套计算，阈值用初始面板防御，不含实战防御增益；按项目统一口径，四件套收益列入实战参考。

未模拟队伍条件与触发覆盖率，因此未加入额外能力提供的 25% 锐暴伤害；也不计影画、特定闪避期间的 15% 增伤、残痕/毁伤循环、敌人抗性、技能倍率。当前期望指数用于驱动盘比较，不是完整 DPS。

回归检查：`claret_test.go` 覆盖防御基数、初始暴伤转换、实战暴伤隔离、二次暴击与上限、玫瑰阈值；`tools/test_claret.js` 覆盖逐级核心、音擎阶数、职业选择、已保存目标重算与显示。
